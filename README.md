# ロット番号読み取り

材料（塗料・樹脂・ボルト・鋼材・溶接材料など）のラベルをiPad・iPhone・Androidのカメラで撮影し、
ロット番号・製造番号を読み取って記録するブラウザ用ツールです。

## できること

- バーコード・QRコードがあれば読み取り、なければ英数字を文字認識
- 写真の上をなぞって読み取る範囲を指定
- 読み違えやすい文字（O/0、I/1、B/8、S/5 など）を赤で表示
- 2液性の材料（塗料・樹脂）は主剤・硬化剤のロットを別々に記録
- 番号の形（例：`YYMMDD-A99`）から製造日を読み取り、有効期限をチェック
- 材料の追加・削除
- 記録一覧をCSVとしてコピー

## 番号の形の書き方

| 記号 | 意味 |
|---|---|
| A | 英字 |
| 9 | 数字 |
| Y | 年（1桁・2桁・4桁） |
| M | 月 |
| D | 日（なければ1日として計算） |

## データの保存について

記録・材料の設定は、使っている端末のブラウザ内（localStorage）にだけ保存されます。
サーバーには送信されません。ブラウザのデータを消すと記録も消えるため、必要に応じてCSVをコピーして保存してください。

## ファイル構成
